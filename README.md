# SUSE Virtualization — How-to learning path

Short, narrated how-to videos for SUSE Virtualization (Harvester), recorded on live lab clusters and grouped
into a learning path: getting started, virtual machines, storage, backup and recovery, networking, live
migration, Rancher integration, day-2 operations, add-ons, scale and limits, ecosystem, observability, and AI
workloads.

Open `index.html` (or the published GitHub Pages site) and pick a track, or search for a task.

- Each video has chapters and English captions (`v/<id>/captions.vtt`).
- Numbers in the list follow the learning path; the videos themselves are not numbered, so new videos can be
  inserted anywhere.
- Recorded with SUSE Virtualization v1.10 (release candidates) unless the video says otherwise.

This folder is generated: do not edit it by hand. The scripts, recorder, and voice-over live in the
`virt-ui-walkthrough` tooling; rebuild with `site.py <project>` and commit the result.
